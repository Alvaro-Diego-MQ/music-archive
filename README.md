# 🎵 Music Archive

Una colección personal de artistas que han marcado mi evolución musical. Este proyecto reúne información, imágenes y contenido visual de algunos de mis artistas favoritos en una interfaz moderna inspirada en Spotify.

## 🌐 Demo

https://music-archive-five.vercel.app/

## ✨ Características

- Diseño moderno inspirado en Spotify.
- Interfaz oscura elegante.
- Totalmente responsive para móviles y escritorio.
- Sección de artistas favoritos.
- Ranking personal de artistas.
- Timeline de mi evolución musical.
- Información sobre cada artista en páginas dedicadas.
- Animaciones suaves con AOS.

## 🎤 Artistas incluidos

- Airbag
- Soda Stereo
- Daft Punk
- Billie Eilish

## 🛠️ Tecnologías utilizadas

- Bootstrap 5
- AOS (Animate On Scroll)
- Font Awesome
